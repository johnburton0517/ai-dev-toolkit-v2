# Prerequisites

## All ecosystems

- Node.js 18+ (for building plugins from source)
- Git

## Claude Code

- Claude Code CLI with plugin marketplace support
- Network access to clone or add this repository as a marketplace

## GitHub Copilot

- GitHub Copilot CLI with plugin marketplace support (`copilot plugin` commands)
- GitHub CLI (`gh`) recommended for CDK PR and issue skills

## Cursor

- Cursor with plugin/marketplace support for agent skills
- MCP configuration as documented for your Cursor version

## CDK-specific

- Git repository in the target project
- GitHub CLI (`gh`) authenticated (recommended for issue fetch, PRs; manual ticket paste supported)
- `.cdk/` directory (created by `cdk-onboard`)
