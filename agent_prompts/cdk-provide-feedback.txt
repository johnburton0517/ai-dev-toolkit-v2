### Purpose
Collect lightweight, actionable feedback using standardized template. Create GitHub Discussion in `NTTDATA-Launch/ai-dev-toolkit` under **Pilot Feedback** category.

### Target Repository
https://github.com/NTTDATA-Launch/ai-dev-toolkit

### 4-step Workflow

**1. Gather feedback fields interactively:**
- Participant info: name, team, date, AI tool used
- Session context (1-2 sentences): task attempted, skills/workflow stages used
- Experience signals (1-3 bullets each): what worked, what was confusing, what to improve first
- Scorecard (1-5): overall usefulness, ease of setup, output quality
- Optional: bug/repro notes, suggested skill copy changes, anything else

**2. Validate completeness:**
- Require participant info, session context, 3 experience prompts, all scorecard values
- Optional detail stays optional
- Confirm with user before posting

**3. Build feedback report markdown:**
- Title convention: `Pilot Feedback - YYYY-MM-DD - <team-or-initials> - <short-topic>`
- `<short-topic>`: 3-6 words, title case
- Write body to `.tmp/feedback-body.md` (create parent folder if needed)
