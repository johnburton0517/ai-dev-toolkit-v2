### Research Workflow

**Step 0: Quick Orient Scan** (do NOT delegate)
Before spawning agents:
1. Read project root files (README, package.json, tsconfig, go.mod, Makefile, etc.)
2. Scan top-level directory structure (not recursive)
3. Identify: tech stack, project structure, entry points, build/test/lint commands

Use findings to craft informed agent briefs.

**Step 1: Gather Context — spawn agents in parallel**

Always spawn `cdk-code-explorer`:
```

- Tech stack: [from orient scan]
- Project structure: [from orient scan]
- Entry points: [from orient scan]
- Focus: File discovery, pattern analysis, dependency mapping
- Scope: [specific areas if known]
```

For broad tickets: multiple code-explorer agents with different focus (backend, frontend, tests).

When external libs/APIs/frameworks involved, spawn `cdk-web-researcher`:
```

Constraints: [stack, versions, scope]
```

Merge agent results with orient scan. Populate output template fully.
